# 市民大道樹冠基礎試算／待核實

目前完成 CHMv2 原始數值讀取與初步研究區裁切；尚未完成現況總綠覆率。土地使用不作為植被排除條件。

## 試算口徑

市民大道一至八段地面主線，加車站以西具市民大道名稱的高架主線；以每20公尺東西座標截線的道路外側交點中值推定軸線，簡化容許3公尺，再左右各250公尺、平端緩衝。EPSG:3826量測。這是待審線位，不是測量中心線；西端分岔交點寬度達228公尺，須重新核對匝道與端點後才可定稿。軸線約11.789公里，試算區約5.877平方公里。

CHMv2 原始像元為 EPSG:3857 約1.194公尺；轉 EPSG:3826 1公尺格網採最近鄰，不代表提高原始解析度。

| 樹冠高度門檻 | 模型候選面積 | 占暫定範圍 |
|---|---:|---:|
| ≥1公尺 | 699,966 m² | 11.91% |
| ≥2公尺 | 603,435 m² | 10.27% |
| ≥5公尺 | 417,414 m² | 7.10% |

以上為門檻敏感度，不是精度區間、也不是現況總綠覆率。模型雲遮罩在此裁切區沒有缺測像元，但橋下遮蔽、模型漏判與其他未知植被仍存在。模型輸出零不等於現況無綠化。

## 年份與限制

原始 metadata 與暫定研究區交集為2018-03-23、2018-08-07；周邊大範圍另有2016-12-18，但未交到本次暫定研究區。2026是新版模型發布年份，不是本區拍攝年份。

樹冠高度不是總植被分類。草地、低灌木、屋頂與庭院植被須由影像核對補繪；樹冠與地面重疊取平面聯集。建築邊緣與高架旁模型候選也需排除誤判，不能只補漏不查誤判。

已核對街景樣點見 IMAGE_REVIEW.md。尚未逐段核對整條走廊，不能宣稱全部核實。Google衛星底圖只顯示版權年，拍攝日未知；不能直接當成2026年現況圖。
